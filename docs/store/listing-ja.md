# Chrome Web Store 掲載文（日本語）

## 短い説明

X上のミュートキーワード追加と投稿者ブロックを、タイムラインを離れず少ない操作で行える非公式拡張機能です。

## 詳細説明

X Context Toolkitは、Xを閲覧中のミュートとブロック操作を簡単にする非公式のChrome拡張機能です。

主な機能：

- ポップアップへ入力したキーワードをXのミュート設定へ追加
- X上で選択したテキストを右クリックメニューからミュート設定へ追加
- 各ポスト右上のボタンから投稿者をブロック
- ミュート追加をバックグラウンドで受け付け、失敗した場合のみ通知

ミュート追加時は、ユーザーの操作を契機にX公式の設定ページを非アクティブな一時タブで開き、処理後に閉じます。既に対象の設定タブが開かれている場合は、そのタブを再利用します。

本拡張機能は入力内容や閲覧情報を開発者のサーバーへ送信・保存しません。広告、アクセス解析、外部API、リモートコードも使用しません。

Xの画面構成が変更された場合、一時的に動作しなくなることがあります。本製品はX Corp.およびその関連会社が提供、承認、提携する製品ではありません。
