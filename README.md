# X Context Toolkit

X(Twitter)でテキストを選択したり、各ポストの🚫ボタンをクリックするだけで、画面遷移なしにミュートキーワード追加・投稿者のブロックができるChrome拡張機能です。

## 機能

### 🎯 主要機能
- **右クリックメニュー（テキスト選択）**: X上でテキストを選択して右クリックでミュートキーワード追加
- **各ポストの🚫ブロックボタン**: タイムライン上の各ポストに常設された🚫ボタンを1クリックするだけで、その投稿者を現在ページ内でブロック（別タブ・別ウィンドウは開かない）
- **ポップアップUI**: 拡張機能アイコンから手動でキーワード追加
- **バックグラウンド処理（ミュートキーワードのみ）**: ミュートキーワード設定は最小化・非フォーカスの専用ウィンドウで実行し、閲覧中のウィンドウにはタブを追加しない
- **自動クローズ**: ミュートキーワード追加成功時は専用ウィンドウを自動で閉じる。失敗時は原因確認のため通常表示に戻して残す
- **DOM操作**: Xの公式ミュート・ブロックUIに直接操作

### ✨ 特徴
- **公式機能と連携**: Xの標準ミュート・ブロック機能を使用
- **画面遷移なし**: ブロックは現在ページ内で完結し、ミュートキーワード追加も閲覧中のタブ・ウィンドウのフォーカスを変えない
- **動的なポストにも追従**: タイムラインをスクロールして新しく表示されたポストにもMutationObserverで🚫ボタンを自動挿入（二重挿入は防止）
- **シンプルなUI**: Bootstrap 5を使用したモダンなデザイン。🚫ボタンも既存のアクション列を崩さない控えめなスタイル
- **通知機能**: 処理結果をわかりやすく通知（失敗時は内容も表示）
- **安全設計**: プロフィールリンクから安全にユーザー名を抽出し、自分自身や別ポストの投稿者、予約パスや不正なリンクは操作しない

## インストール

### 1. リポジトリをクローン
```bash
git clone https://github.com/your-username/x-context-toolkit.git
cd x-context-toolkit
```

### 2. 依存関係をインストール
```bash
npm install
```

### 3. ビルド
```bash
npm run build
```

### 4. Chrome拡張機能として読み込み
1. Chrome で `chrome://extensions/` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `dist` フォルダを選択

## 使い方

### 方法1: 右クリックメニュー（テキスト選択）
1. X(Twitter)でミュートしたいテキストを選択
2. 右クリックして「X ミュートキーワードに追加」を選択
3. 閲覧中のウィンドウにはタブを追加せず、最小化・非フォーカスの専用ウィンドウでミュートキーワード設定ページを開いて入力
4. 成功すると専用ウィンドウは自動で閉じる。失敗時は通常表示に戻るので、内容を確認する

### 方法2: 各ポストの🚫ブロックボタン
1. タイムライン上の各ポストのアクション列（返信・リポスト・いいねの近く）に表示される🚫ボタンをクリック
2. そのポストの投稿者に対して、現在のページ内でXの公式メニュー（その他メニュー→ブロック→確認ダイアログ）が自動操作される。別タブ・別ウィンドウは一切開かない
3. 操作中はボタンが無効化され、成功すると✅で完了を表示する
4. 投稿者を特定できない場合・自分自身の投稿・失敗時はボタンが再度クリック可能な状態に戻り、通知でエラー内容を確認できる

### 方法3: ポップアップ
1. 拡張機能アイコンをクリック
2. キーワードを入力して「追加」ボタンをクリック
3. 最小化・非フォーカスの専用ウィンドウでミュートキーワード設定ページを開いて入力し、成功時は自動で閉じる

## 技術仕様

### 開発環境
- **Node.js** + **npm**
- **React 19** + **TypeScript**
- **Bootstrap 5** (UI フレームワーク)
- **Vite** + **CRX.js** (ビルドツール)

### プロジェクト構成
```
src/
├── background/         # バックグラウンドサービス
├── content/           # コンテンツスクリプト
├── popup/             # ポップアップUI
└── utils/             # ユーティリティ関数
```

### コマンド
```bash
# 開発サーバー起動
npm run dev

# ビルド
npm run build

# リント
npm run lint

# テスト
npm test
```

### Chrome Web Store公開用パッケージ

```bash
npm run store:assets  # 掲載画像を再生成（Python 3 / Pillowが必要）
npm run release       # release/へ展開版とアップロード用ZIPを生成
```

- `release/x-context-toolkit-v<version>/`: Chrome/Vivaldiでのローカル動作確認用
- `release/x-context-toolkit-v<version>.zip`: Chrome Web Storeアップロード用
- `store-assets/`: ストアアイコン、プロモ画像、スクリーンショット
- `docs/store/`: 掲載文、プライバシーポリシー、Privacy practices、公開チェックリスト

公開時は[公開チェックリスト](docs/store/publish-checklist-ja.md)を確認してください。

## セキュリティ

この拡張機能は**防御的な用途**のみを目的としています：
- X(Twitter)の公式ミュート機能を使用
- 悪意のあるコードは含まれていません
- ユーザーデータを外部に送信しません

## 対応ブラウザ

- Google Chrome (Manifest V3対応)
- Microsoft Edge
- その他Chromiumベースブラウザ

## 対応サイト

- `https://x.com/*`
- `https://twitter.com/*`
